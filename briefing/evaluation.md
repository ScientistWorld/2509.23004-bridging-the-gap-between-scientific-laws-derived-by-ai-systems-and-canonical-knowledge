# Evaluation Protocol

## Interface

A method is a solver script `scripts/solvers/<name>.sh`. The evaluators discover
every such script and call it once per instance:

```
bash scripts/solvers/<name>.sh <instance.json> <output.json>
```

with the working directory at the workspace root and the per-instance budget in
the environment variable `ABDUCTION_TIME_LIMIT` (60 seconds, wall clock; the
process group is killed 5 seconds later). The solver writes

```json
{"candidate_sets": [["poly", "..."], ["poly"], "..."]}
```

ranked best first. Any other fields are ignored. The method needs no training,
so the hidden test runs the solver directly on held-out instances that only the
evaluator holds.

* `bash scripts/evaluate_train.sh` scores every solver on the visible train
  slice and writes `scoring/scores_train.json` (`--only NAME ...` re-scores
  selected solvers, `--max-instances N` gives a quick smoke run).
* `bash scripts/evaluate_test.sh` (no arguments) is the hidden test; it writes
  `scoring/scores_test.json`.

## What is checked per candidate set

Only the first five sets count. A set is malformed (no credit, still uses a
slot) if it is empty, has more than `num_missing` polynomials, or contains a
string that is not a polynomial over the instance variables within the size
limits (at most 4000 characters, 400 terms, total degree 24, exponents 12). All
checks are exact Groebner basis computations in Singular:

* **derives**: every target lies in the ideal generated by the known axioms and
  the set;
* **sound**: every polynomial of the set vanishes on every solution of the
  complete hidden theory at which the declared nonzero quantities are nonzero
  (radical membership in the complete theory saturated by their product). A
  true law that needs a physical quantity to be nonzero (for example after
  dividing by it) is sound; a contradiction, a law forcing a nonzero quantity
  to zero, or a law stronger than the theory is not;
* **nontrivial**: no polynomial of the set already lies in the ideal of the
  known axioms, the targets, and the targets with their monomial factors in
  nonzero quantities divided out (restating the target is not an explanation);
* **valid** = derives and sound and nontrivial;
* **recovered** = valid, and every removed axiom lies in the ideal of the known
  axioms plus the set, saturated by the declared nonzero variables.

With several targets (multiple-consequence experiment) a set derives only when
it makes every target derivable.

A run that crashes, exceeds the time limit, or writes malformed JSON fails the
instance: it receives the worst value in every scored metric.

## Metrics (per experiment, all in [0, 1])

| metric | direction | meaning |
|---|---|---|
| `recovery_rate` | higher | instances where some considered set is recovered (scored for single-axiom and multiple-consequence removals; a diagnostic with coefficient 0 for the single-target two- and three-axiom removals) |
| `explanation_rate` | higher | instances where some considered set is valid (scored for two- and three-axiom removals; elsewhere a diagnostic) |
| `top1_success_rate` | higher | instances whose first set succeeds (recovered for single-axiom and multiple-consequence instances, valid for two- and three-axiom instances) |
| `unsound_rate` | lower | instances where some considered set derives the targets but is unsound, plus failed instances and instances whose sets the evaluator could not verify |
| `axiom_recovery_rate` | higher | multiple-consequence only: mean fraction of the removed axioms recovered by the best valid set; a diagnostic (every instance is identifiable, so it equals `recovery_rate`) |
| `failed_rate`, `mean_candidate_sets`, `instances` | — | diagnostics, not scored |

Denominators are the fixed instance counts of the slice. Every solver on disk
gets a row in every experiment.

## Experiments and ranking

`single_missing_axiom` (weight 0.30, primary `recovery_rate`; 64 held-out
instances), `two_missing_axioms` (0.25, primary `explanation_rate`; 55),
`three_missing_axioms` (0.20, primary `explanation_rate`; 40),
`multiple_consequences` (0.25, primary `recovery_rate`; 59 instances with two to
five removed axioms and several observed laws). Every experiment also scores
`top1_success_rate` (coefficient 0.3) and the constraint `unsound_rate` (0.3).
A method's rank sums,
over experiments and scored metrics, weight times coefficient magnitude times
its improvement over the reference in the metric's better direction, each
metric normalized by its spread across ranked attempts. Coefficients are in
`scoring/reference.json`.

## Baselines

`no_abduction_baseline` proposes nothing. `enumerative_baseline` enumerates
small binomial axioms with small integer constants, simplest first (the first
6000 grammar candidates per instance, so its result does not depend on machine
speed), keeping those that make the target derivable without forcing a nonzero
quantity to zero.
